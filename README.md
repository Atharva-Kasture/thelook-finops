# theLook FinOps Analytics Project

Cost-conscious analysis of theLook e-commerce data using Google BigQuery, SQL, Python (Pandas, NumPy, Seaborn) and Google Colab.

## Structure
- `docs/` architecture mapping, data dictionary, findings
- `sql/` one file per task, e.g. `2_6_refactor_q1.sql`
- `notebooks/` Colab notebook
- `data/` local data files (not versioned)
